# AI Document Q&A

An AI-powered chatbot that lets you upload any PDF and ask questions about it using natural language.

## Live Demo
[Click here to try it](https://sharonkopuri-docs.streamlit.app)

## Features
- Upload any PDF document
- Ask questions in plain English
- Get instant AI-powered answers using Groq LLM

## Tech Stack
- Python
- Streamlit
- Groq API (LLaMA 3.3)
- PyPDF

## How to Run Locally
pip install -r requirements.txt
streamlit run app.py
